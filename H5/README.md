# 原子轨道三维可视化 · Hydrogen Orbital Visualizer

一个**移动端友好、可离线运行**的交互式 H5 工具，用三维图形直观展示**氢原子波函数**（Z = 1；角向部分对类氢离子同样适用，径向部分按 Z = 1 实现，程序不提供核电荷数调节），帮助学生/教育工作者理解抽象的量子力学概念。

## ✨ 功能特性

- **量子数控制**：滑块与**数字输入框**双通道调节主量子数 `n`（1–6）、角量子数 `l`、磁量子数 `m`，实时联动（l 上限随 n、m 范围随 l 自动收窄）；输入框会校验类型与范围，非法值标红提示且不改变状态。
- **三维轨道**：按概率密度 `|ψ|²` 实时生成（**默认等值面**，可切粒子云）
  - **粒子云**：按 `|ψ|²` 重要性采样数万个点，统计上即真实电子分布。
  - **等值面**：在网格上走四面体行进（marching tetrahedra）提取等值面，**判据可切换 `|ψ|` / `|ψ|²`**，阈值可调；经顶点焊接 + Taubin 平滑 + 一致朝外绕向处理，表面光滑。
    > `|ψ| = c` 与 `|ψ|² = c²` 是同一族曲面，故切换判据**改变的是读数的含义而非形状**：同一读数 `f`，按 `|ψ|²` 计为 `f·|ψ|²max`，按 `|ψ|` 计等价于 `f²·|ψ|²max`（`f<1` 时更小）→ 得到**更大**的表面。面板会实时显示两者的换算，如 `30.0% |ψ|² ⟺ 54.8% |ψ|`。
  - 网格范围随阈值自适应（收紧到等值面实际外延，而非波函数渐近尾部），同分辨率下格距可细数倍——这是分辨 p 轨道节面附近两瓣窄缝的关键。
  - 阈值滑块为**对数刻度**、覆盖 `0.02%–80%`（线性刻度下低端拖不到）；面板按当前轨道给出**推荐阈值**（取最弱一层径向壳峰值的 40%）并可一键采用——各层壳峰值相差悬殊（3p `100/11.9`、4p `100/11.1/4.2`、4s `100/1.8/0.42/0.18`），任何固定默认值都必然在某些轨道上把外层壳整片切掉。
  - **三维着色**：粒子云与等值面共用同一套配色 —— **相位色（正负瓣）**（实函数 → ±红/青，判据是**完整 ψ 的符号** `sign(R(r)·Y)`，故径向节点处的符号翻转也能看到；复函数 → 彩虹相位缠绕）/ **支壳层色**（按 s/p/d/f 着色，不显示正负）。l=0 时角向函数为常数、正负恒定，相位色无信息，自动置灰。
- **实函数 / 复函数** 双模式：
  - 实球谐 → 经典"瓣状"轨道（pz、px、dxy、dz²…）。
  - 复球谐 → 密度绕 z 轴对称的"环/锥面"，并按相位（arg ψ）彩虹着色。
- **多维2D视图**（手绘 Canvas，无图表依赖）：
  - 径向曲线：`R(r) / R(r)² / D(r) / D(r)²` 多选叠加，各自按峰值归一化。
  - 角度分布：以 (θ, φ) 为自变量、**自原点沿该方向引射线、长度为 `|Y|` 或 `|Y|²` 的三维曲面**，可拖拽旋转；着色只由实/复决定（实函数按 `sign(Y)` 分 ±红/青，复函数按相位着色，**与三维、截面同色**），**与判据无关**——切 `|Y| ↔ |Y|²` 只改曲面轮廓，颜色不变。
  - 截面密度：`xy / xz / yz` 平面，三种模式 —— **密度着色** / **相位着色** / **无填色等高线**（8 层对数间距、数值标注在线上、白线标出节面 ψ=0）；恰为节点面时提示"本平面为节点面"。
- **公式展示**：KaTeX 实时渲染当前波函数的数学表达式（代入具体 n/l/m 与归一化系数），且 `P_l^m(cosθ)` **展开为显式多项式**（如 `P_1^1 = -sinθ`）。
- **交互**：拖拽旋转、滚轮/双指缩放、右键（或 Shift+拖）平移、自动旋转、复位；桌面 / 平板 / 手机响应式自适配。
  - 旋转由**四元数轨道控制器**驱动：偏航绕**相机自身 Y（屏幕竖直）**、俯仰绕**相机自身 X（屏幕水平）**，均为相机局部系四元数相乘，不经过欧拉角，**从原理上避免万向节锁**，且允许自由翻滚（无极点限位）。
    > 偏航刻意**不用世界 Z 轴**：若用世界 Z，当视线俯到极点附近时世界 Z 与视线重合，"左右拖"会退化成绕视线的滚转，用户会感觉方向反了；改用局部 Y 后，任何朝向下左右拖都绕屏幕竖直轴转，方向始终一致。

## 🚀 如何运行

**方式一（推荐，离线）**：直接双击打开 `index.html`。
项目把依赖（Three.js / KaTeX）本地化到 `libs/` 并采用**全局构建**，因此 `file://` 双击即可离线运行，无需联网、无需服务器。

**方式二（可选）**：用本地静态服务器打开，便于用开发者工具调试：

```bash
cd H5
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> 说明：若改用 ES Module 版本的 Three.js，则必须通过服务器访问（`file://` 下模块会被 CORS 拦截）；本工具刻意选用全局构建以支持双击离线运行。

## 🧮 物理与数学约定

- 玻尔半径 `a₀ = 1`（长度以 a₀ 为单位）；球坐标 `(r, θ, φ)`，θ 为与 z 轴的极角（**z 为量化轴**，三维中竖直）。
- 波函数 `ψ_{n,l,m} = R_{n,l}(r) · Y_{l,m}(θ, φ)`，已归一化（`∫|ψ|²dV = 1`）。
- **径向**：`R_{n,l}` 含广义拉盖尔多项式 `L_{n-l-1}^{2l+1}`；`D(r) = r²R(r)²` 为径向分布函数。
- **球谐**：复模式 `Y_l^m = N·P_l^{|m|}(cosθ)·e^{imφ}`（含 Condon–Shortley 相因子）；实模式由复球谐组合得到 cos/sin(mφ) 型实轨道。
- 数学均为纯 JS 递推实现（拉盖尔/勒让德/球谐、复数运算），n≤6 时阶乘不越界、float64 精确，故无需 NumPy/Pyodide（后者 ~15MB、移动端首屏慢）。

## ⚙️ 关键技术决策

| 决策 | 原因 |
|---|---|
| 纯 JS 手写数学（弃 NumPy/Pyodide） | 移动端秒开；波函数所需数学仅需少量递推，精确且轻量 |
| Three.js r147 全局构建 | r148 起非模块 `OrbitControls` 被移除，且新版为 ES Module（`file://` 下被 CORS 拦截）；全局构建可双击离线运行 |
| **四元数轨道控制器**（不用 `OrbitControls`） | `OrbitControls` 用球坐标 + up 向量描述朝向，视线与 up 平行时存在万向节锁；改为四元数累积旋转（偏航、俯仰都取相机局部轴：Y 轴对应屏幕竖直、X 轴对应屏幕水平），全程不经欧拉角，无奇异点，另加 ±Z 极点软限位防止翻过头 |
| 等值面用 marching **tetrahedra**（非 cubes） | 免去 256×16 巨型查找表，规则简单、必定正确；三角形略多，用较高网格分辨率补偿 |
| 三维画布高度由 JS 按视口算（`layout.js`），不写死 | 写死 `clamp(280px, 44vh, 470px)` 时，"高度=窗口高"这个直觉等式从不成立——顶端还有顶栏、卡片标题、内边距。改为量出画布顶端在文档中的位置，用 `视口可见高 − 该位置 − 余量` 下发 CSS 变量，移动端读 `visualViewport` 以正确处理地址栏收放 |
| 相机取景由 `fov + aspect` 共同决定，不用"距离 = 尺度 × 常数" | 固定倍数下留白会随画布宽高比漂移：宽扁画布上轨道顶满上下边缘，竖屏还会被左右切掉。改用"需要容纳的半尺寸 ÷ tan(fov/2)"并同时校验水平方向，任何画布比例下留白一致、永不裁切 |
| 智能体动作**排成分镜队列、由用户逐步确认**（可前进 / 回退 / 连播 / 重播） | 一次下发的动作若同步 tight-loop 执行，十几个动作会在几十毫秒内全落地，学生只看到最终画面、中间每步都"闪"过去，演示等于没演示；而固定时长的自动连播又不由学生掌握节奏。改为"入队 + 立即返回 + 闸门等待"：工具不再阻塞对话循环，节奏完全交给学生。**每步执行前存一份完整状态快照**，「上一步」据此精确还原——反向执行动作做不到这件事，因为动作带副作用（例如 `setQuantumNumbers` 会顺手退出叠加态） |
| 闸门放在"执行之前"而不是"执行之后" | 两种写法在逐步前进时完全等价，但"先闸门"让循环可以从**任意一步**恢复：演示播完之后点「上一步」，只需重起循环并标记"先停闸门"，就能退回去重看而不立刻执行 |
| 演示预设可增删（存 localStorage） | 内置预设表达不了"不等性杂化"这类系数不等的组合。智能体现场构造的示意系数对话一过就没了，存成预设后学生可一键复现、反复对照——从"一次回答"变成"留在工具里的教具" |
| 智能体**绝不静默失败**：必须读 `finish_reason`，空正文也要有交代 | 输出上限被触发时，早期版本把 `finish_reason` 解析出来却没有任何一处读它，界面上便只剩一个**空白气泡**——用户只会觉得工具坏了。现在：截断即自动续写（有次数上限）并提示；正文为空时区分 `length` / `tool_calls` / 其他三种成因，并附上 `finish_reason` 与 token 用量作为证据 |
| 流式请求显式索取 `usage`（`stream_options.include_usage`） | 流式响应默认**不返回 usage**，没有它就只能猜"输出为什么是空的"。同时把 `stream_options` 与 `max_tokens` 做成**可降级字段**：服务端 400 报错点名了哪个字段，就自动去掉它重试一次。否则用户把输出上限填得比模型上限大一点，整个功能就直接不可用了 |
| 2D 图表手绘 Canvas | 三种图表形态各异，手绘控制力强、零依赖、与暗色主题统一 |

## 🔧 扩展指南

- **新增渲染/视图**：在对应模块（`render3d.js` / `charts.js`）加函数，并在 `main.js` 的 `updateViewer` / `updateCharts` 中调用。
- **调整颜色**：改 `math.js` 的 `SUBSHELL_COLOR`（s/p/d/f/g）；相位映射改 `phaseColor`。
- **量子数上限**：`index.html` 的 `nSlider` `max` 与 `main.js` 的 `maxL` 上限（5）联动。
- **性能**：粒子数滑块控制点数；等值面网格分辨率在 `main.js` 按设备取 `isMobile ? 46 : 68`。

## ⚠️ 已知取舍

- 等值面在网格分辨率与平滑之间折中；移动端用较低分辨率以保证流畅（可在 `main.js` 调整）。
- 复模式单视角相位着色所见 φ 范围有限，可拖拽旋转观察完整相位缠绕。
- 「教材对照表」（R 表 / Y 表）依赖 `assets/ref/` 下的两张表格图片；该目录未随仓库分发，
  图片缺失时面板会显示查阅指引而不是裂图（书目见根 [README](../README.md) 的「参考书目」）。
