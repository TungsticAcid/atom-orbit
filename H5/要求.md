### 🚀 原子轨道三维可视化交互工具 · Vibe Coding 提示词

#### 1. 项目概述
> 请作为我的“技术联合创始人”，帮我开发一个**移动端友好的、交互式H5原子轨道可视化工具**。
>
> 它的核心目标是：**通过三维图形直观展示类氢原子波函数，帮助学生和教育工作者理解抽象的量子力学概念**。要能够清晰地展示**波函数模、模平方、径向波函数、径向波函数平方、径向分布函数、径向分布平方、角度分布函数、角度分布函数平方**，并且支持**实函数波函数**和**复函数波函数**两种形式的波函数。

#### 2. 技术栈
> 请使用以下技术栈进行开发：
> *   **核心库**：`Three.js` 用于 3D WebGL 渲染。
> *   **数学计算**：`NumPy` (通过 `Pyodide` 或在服务端) 或 `math.js` 来计算波函数。
> *   **公式渲染**：`KaTeX` 用于在界面上美观地显示波函数数学公式。
> *   **前端**：原生 JavaScript (ES6+) 或 React/Vue，配合 `CSS3` 实现现代化、响应式的UI。

#### 3. 核心功能与交互
> 我需要实现以下功能，请确保它们可以流畅地协同工作：
> 1.  **量子数控制**：提供滑块或输入框，让用户可以动态调整**主量子数 (n)**、**角量子数 (l)** 和**磁量子数 (m)**。
> 2.  **三维轨道可视化**：根据选中的量子数，实时计算并渲染出对应的三维原子轨道形状。
> 3.  支持**实函数波函数**和**复函数波函数**两种形式的波函数。
> 4.  **多维度视图**：
>     *   **3D 概率密度云图**：用粒子云或等值面的方式展示电子在空间中的概率分布。
>     *   **2D 截面图**：可以显示在特定平面（如 xy, xz, yz 平面）上的概率密度截面。
>     *   **径向波函数图**：以 2D 曲线图形式，单独展示径向概率密度分布 `R(r)`。
>     *   **径向密度函数图**：`R(r)^2`
>     *   **径向分布函数图**：`D(r)`
>     *   **角度分布图**：以 2D 极坐标图或曲面图形式，单独展示角度分布 `Y(θ, φ)`。
> 5.  **交互控制**：
>     *   支持鼠标/手指拖拽旋转、滚轮缩放三维场景。
>     *   界面布局应清晰，所有控制面板（量子数、显示模式、视图切换）应直观易用。

#### 4. 视觉与教育设计
> *   **色彩方案**：不同轨道类型（s, p, d, f）使用不同的颜色进行区分，并保持视觉上的美观与专业。
> *   **公式展示**：在界面的显著位置，用 LaTeX 实时显示当前波函数的数学表达式。
> *   **响应式设计**：确保在手机、平板和电脑屏幕上都能获得良好的浏览体验。

#### 5. 交付物与质量标准
